|---|---|

| Gênero/forma textual | Escolha narrativa independente da aparência; opções finais por idioma ainda serão fechadas |

## Conjunto para a chegada

Cada ID representa um conjunto completo na primeira versão. Depois da chegada, o conjunto escolhido é apresentado como roupa do dia a dia.

| ID | Rótulo inicial | Direção visual |
|---|---|---|
| `arrival-clothes-01` | Casual claro | Camiseta clara, calça simples e cores leves |
| `arrival-clothes-02` | Casual escuro | Camiseta escura, calça e contraste moderado |
| `arrival-clothes-03` | Confortável | Blusa solta, calça confortável e tons suaves |

| `arrival-clothes-05` | Prático | Roupa simples, resistente e adequada para carregar malas |

Na tela do criador, cada conjunto mostra também a lista/descrição do que visualmente o compõe.

## Composição dos IDs

Uma aparência salva deve registrar apenas escolhas cosméticas, por exemplo:

```js
{
  name: 'nome escolhido pelo jogador',
  genderProfile: 'perfil textual escolhido',
  skin: 'skin-03',
  body: 'body-02',
  height: 'height-03',
  face: 'face-01',
  eyes: 'eyes-05',
  eyeColor: 'eye-color-01',
  hair: 'hair-02',
  hairColor: 'hair-color-02',
  headwear: 'headwear-01',
  facialHair: 'facial-hair-01',
  arrivalClothes: 'arrival-clothes-04',
  fishingClothes: 'fishing-clothes-02',
  shoes: 'shoes-03',
  accessory: 'accessory-01'
}
```

O perfil textual não deve ser inferido desses IDs. A aparência também não deve revelar ou substituir o gênero escolhido.
