# Bites & Baits — Catálogo Completo de Peixes por Bioma
> Documento de design. Nem todas as espécies precisam entrar no jogo.
> Boss = espécie de alta dificuldade, backtracking incentivado.
> Tier de gear mínimo sugerido para captura viável com RITMADO (jogador padrão).

## Resumo — Distribuição de Bosses por Mapa

| Mapa                  | Boss principal      | Boss secundário    | Chance c/ gear básico |
|-----------------------|--------------------|--------------------|----------------------|
| Rio                   | Dourado            | Pintado            | 3–5%                 |
| Lago / Represa        | Pirarucu           | —                  | 1–2%                 |
| Cachoeira             | Jaú                | Bicuda             | 2–3%                 |
| Igarapé / Amazônia    | Pirarucu / Piraíba | —                  | 1%                   |
| Estuário / Mangue     | Camurim            | Robalo             | 3–5%                 |
| Foz / Costa           | Cação              | Robalo             | 1–2%                 |
| Baía / Costão         | Cherne / Barracuda | Badejo             | 2–3%                 |
| Alto Mar              | Atum               | Marlim / Agulhão   | <1%                  |

> **Regra de backtracking:** O jogador vê/ouve o boss no primeiro contato (feedback de fuga dramático) mas snappeia ou perde quase sempre com gear básico. Com gear avançado, captura viável. Incentivo orgânico para voltar.
